## 一、数据资产清单（四类）

| 类 | 位置 | 性质 | 入 git | 随包分发 |
|---|---|---|---|---|
| A 内置区间知识库 | `src/checkup_ledger/data/indicators.yaml` | **运行时必需**，逐条挂来源标注 | ✅ | ✅（随包白名单） |

**A 放包内、B/C/D 放仓库顶层 `data/` 的理由**（见 `plan/02` 第三节）：A 是"交付物内可达全部承诺能力"的承重件，必须进安装面；B/C/D 是开发期资产与留档，不该随用户安装落盘。

**台账是生成物**（C）：`tools/verify_ledger.py --update` 重算全部 sha256 写入；**手改台账 = 与实算漂移**，配守门测试当场检出。判据 = 台账每格都能由脚本从被登记对象复算出来。

## 二、A 类：内置区间知识库 schema（M1 建立，M0 定 schema）

```yaml
# src/checkup_ledger/data/indicators.yaml  ·  DO NOT HAND-EDIT 派生字段
schema_version: 1
updated: 2026-10-16
disclaimer: >
  本字典仅用于检验结果的机械判定（H/L），不构成诊断依据。
  各医疗机构应以本机构 LIS 打印区间为最终准绳；本字典区间为常见项默认值，以报告单和医嘱为准。
indicators:
  - canonical_name: ALT
    display_name: 丙氨酸氨基转移酶
    aliases: [谷丙转氨酶, ALT, GPT, 丙氨酸氨基转移酶]
    unit: U/L
    unit_aliases: [U/L, IU/L, u/l, U/L(速率法)]
    # 默认区间：仅在报告未自印区间时兜底使用
    default_range:
      low: 9
      high: 50
      bounds: closed          # closed: [low, high] 闭区间；open: 开区间
      applies_to: {sex: any}  # 区分性别的项目须显式写出（如 any|male|female）
    source:
      standard: WS/T 404.1-2012
      status: pending         # pending | verified —— 仅 verified 可进判定路径
      note: 常见项默认值；以报告单和医嘱为准
      evidence: ""            # verified 时必填：核对渠道 + 日期
```

### 三条硬纪律

1. **未挂来源核对的条目不得生效**——loader 入口硬门：`source.standard` 缺失、或 `source.status` 不在枚举内、或 `status: verified` 而 `evidence` 为空 → **拒绝加载该条目**，并在"未启用清单"显式列出原因。**缺锚点的条目拒绝被引擎加载**（不是静默照常判）。
2. **`status: pending` 不进判定路径**——可作为别名/展示信息（否则"待核对"期间该项目凭空消失），但**绝不作为区间默认值来源**。
3. **区间数值只在 YAML 一处定义**——零字面量门禁（M1 建立）扫描 `src/`、`tools/`、`tests/` 源码，token 集 = 本 YAML 全部上下限数值（词边界），豁免口径写死（0/1 等结构常数）。**防御性常数不是豁免理由**。

### 与题目"双先例"的对应

| 先例 | 借鉴点 | 本项目落法 |
|---|---|---|
| LabLens（95 项 YAML，来源标注分册） | YAML schema + 逐条挂分册来源 | `source.standard` + `status` + `evidence` 三字段 |
| bloodio（printed ranges 明示） | 报告自印优先 | `default_range` 与 `ref_range_printed` 分离，判定层三级优先 |

### WS/T 404/405 全文不可直连的处置（题目已实测 412/502）

- **不作底座**，仅作**来源标注引用**；分册号沿用 lablens 已标注分册，**入库时逐条核对**。
- 拿不到原文的条目标 `status: pending` 并如实记 `evidence: 待核对（渠道：wsbz 412/502）`。
- **宁拒判，不臆造**：`pending` 多一项，就是多一项走"无区间 → 拒判"，这符合题目"拒判"设计，不是缺陷。

## 三、B 类：合成报告样例集 + 植入真值（M1 建立）

### 生成器纪律（sprint「确定性生成纪律」）

- **禁 stdlib `random`、禁 `set` 迭代序、禁系统时钟**——自研确定性 RNG（splitmix64 变体），固定 seed 可复现。
- 产物**无时间戳字段**；两次运行**逐字节一致**，配"再生成位级一致"守门测试（`--check`）。
- 若产 zip 型容器（后续若产 docx 形态报告）：`ZIP_STORED` + `create_system=0` + `external_attr` 常量 + 固定 `date_time=(1980,1,1,0,0,0)`——否则跨平台重生成字节必漂。
- 落盘一律经 `serialize.write_atomic()`（写盘单点）。

### 目录结构

```
data/samples/
  cases/                    # 输入：合成报告（文本层可读的 PDF/文本 + 少量扫描图）
    case-001-张三-2023.txt
    case-002-张三-2024.txt
    ...
  truth/                    # 植入真值（唯一真值源）
    case-001.truth.json
  manifest.json             # 覆盖度门槛 + 逐 case 形态登记 + sha256
  generator/                # 生成器（与 samples 同目录，便于对账）
    gen_samples.py
```

### 真值库形态（关键：只存"输入与期望"，**不存观测**）

```json
{
  "case_id": "case-002-张三-2024",
  "subject": "张三",
  "date": "2024-03-11",
  "institution": "示例体检中心A",
  "expected": [
    {"canonical_name": "ALT", "value": 47.0, "unit": "U/L",
     "expected_flag": "high",
     "expected_range_source": "report_printed",
     "printed_range": {"low": 9, "high": 40, "bounds": "closed"}}
  ],
  "expected_trends": [
    {"canonical_name": "ALT", "direction": "up", "delta": 15.0}
  ]
}
```

**红线**：真值库里**不得出现 `observed`/`actual`/`got` 一类字段**——冻结的若是"观测"，基准就退化成"比对两份预先算好的答案"，引擎全坏也全绿。**观测由观测器在基准运行时实算**。守门测试扫描字段名，出现即红。

**真值与引擎共用同一处判定规则定义**（`engine/compare.py`），**禁止手写第二口径**。真值生成器 import 同一函数产出期望值——不是复制一份判定逻辑。

### 覆盖度门槛（manifest 下发，数据非代码）

| 维度 | 最低覆盖 | 为何必须 |
|---|---|---|
| 指标域 | 血常规 / 肝功能 / 血脂 / 肾功能 / 血糖，各 ≥1 项 | 防"只覆盖一项指标"的假全绿 |
| 判定形态 | `high` / `low` / `normal` / `not_assessed` 各 ≥1 | 四态齐全，尤其拒判不能被漏 |
| 区间来源 | `report_printed` / `builtin_default` / `none` 各 ≥1 | 三级优先必须都有用例 |
| **自印覆盖默认值** | ≥1（同一指标自印与默认区间不同，且结论相反） | 直接验"最优先"语义；没有它三级优先从未被测 |
| 边界形态 | `threshold_exact`（恰在边界）≥1、`near_miss`（差一点）≥1 | 边界开闭语义与"不到不命中" |
| 趋势点 | 升 / 降 / 平稳各 ≥1 | 趋势三态 |
| 低置信复核 | ≥1（含"未复核不落库"阴性对照） | 复核闭环 |
| 单位变体 | ≥1（同一指标两种单位写法归一） | 单位归一 |
| 性别相关 | ≥1（`applies_to.sex` 生效与"不该命中"反向样例） | 适用域（sprint「适用域是硬门」） |
| **反向样例** | ≥1（"这条规则不该命中"） | 只测"该命中"，适用域写错永远不红 |

**覆盖声明要"总数/采样数双登记"** + 显式写"抽样覆盖非穷举"——防"各有件"被读成"全穷举"。

### 性别/适用域的硬门（提前设防）

`applies_to: {sex: ...}` 是**原文/常识自带的主体限制**，必须落成字段而非写 `any`：男性血红蛋白区间判给女性样本 = 拿不适用的区间判"异常"（冤枉用户，且样例集恰好合规时基准照常全绿）。**基准必须含"这条区间不该命中该样本"的用例**。

## 四、单位与口径纪律

**数值口径唯一源 = `data/README.md` 第五节**（区间三级优先 / H-L 判定 / 趋势点 / 低置信阈值），本文档与代码一律引用，**不重写**。补充：

### 单位归一表（M2 建立，与 YAML `unit_aliases` 同源）

- **最长优先匹配**：`mg` > `g`；`mmol/L` > `mol/L`。短串吃长串前缀 = 值静默放大/缩小一千倍。
- **换算基准要问"两边同基准吗"**：单位相同 ≠ 基准相同。本项目首期**只做同量纲单位归一**（`IU/L`↔`U/L`、大小写与括号注归一）；**跨量纲换算（如 mg/dL ↔ mmol/L）不做**——各指标换算系数是另一份口径，首期宁拒判不换算（认不出 → `pending(unit_unmapped)`）。
- **数量词/数值抽取失败要显式标注"未定位"**，绝不静默填默认值（"没看到"与"看到了但没抽到"是两种结论）。

## 五、数据来源可获取性（延续 `data/README.md` 记录）

| 数据源 | 状态 | 本计划处置 |
|---|---|---|
| WS/T 404/405 全文（卫健委 wsbz / 工标网） | ⬜ 不可直连（412/502，全文付费） | 不作底座；仅作来源标注引用，逐条核对方册号 |
| 各体检机构真实报告 | 🚫 红线禁用 | 永不入库/入 git/入示例目录；一律用合成件 |
| 合成样例（本项目自制） | ✅ 唯一合规输入源 | 程序化生成 + 植入真值 |
| 开源先例（lablens / bloodio / RapidOCR） | ✅ 已核对（`data/README.md`） | 借鉴设计模式，不复制其数据内容 |

**降级方案合法性**（题目已论证）：LabLens（95 项手工 YAML）与 bloodio（printed ranges 优先）双先例证明"报告自印区间 > 标注来源默认值 > 拒判"是该细分最佳实践，**非妥协**。
